# ROS2_MultiUAV_3D

Multi-UAV 3D mission planning and execution in **ROS2 (Humble)** / **Aerostack2** / **Gazebo** with **DECK_GA** (DCKmeans + Distance Efficient Genetic Algorithm path planning algorithm).

## Repository Structure
- `aerostack_examples/` : Aerostack2 / Gazebo project launch files and configs
- `deckga_ros2/` : ROS2/Aerostack-facing Python scripts  
  - `rviz_paths_node.py` : publishes the planned paths to RViz as markers (`/deckga/markers`)
  - `deckga_execute.py` : executes the same transformed path in Aerostack2
- `DECK_GA.py`, `DCKmeans.py`, `GA_path_planning.py` : DECK_GA offline planning components
- `data/points/` : waypoint generator + datasets (`.pkl`)
- `results/` : outputs/figures generated by the planner (created at runtime)

---

## Prerequisites
You need:
- Ubuntu 22.04
- ROS2 Humble installed
- Aerostack2 installed (and available at `/opt/ros/humble/share/aerostack2/`)
- Gazebo (as used by the included Aerostack example project)
- Python3 + common scientific packages (e.g., numpy)

---

## Coordinate Transform (Important)
Both **RViz visualization** and **Aerostack execution** apply the **same transform** (hardcoded defaults inside both scripts):

- `coord_mode = original`
- `scale_xy = 0.05`
- `scale_z  = 0.05`
- `z_offset = 2.5`
- `z_min    = 3.0` (safety clamp)

Meaning: the planner can operate in a larger coordinate range, while the executed/visualised path is scaled down for a better Gazebo/Aerostack flight envelope.

## Quickstart: Run the Full Experiment (Terminals 0–6)

### Terminal 0 — Generate points (Z 10 to 100) + Run DECK_GA
```bash
cd ~/Documents/GitHub/ROS2_MultiUAV_3D

SEED=11
N=30
DATASET="data/points/points_seed${SEED}_n${N}_z10_100.pkl"

python3 data/points/generate_points_xyz.py \
  --n ${N} \
  --x -100 100 \
  --y -100 100 \
  --z 10 100 \
  --seed ${SEED} \
  --out "${DATASET}"

python3 DECK_GA.py \
  --points_pkl "${DATASET}" \
  --num_uavs 3 \
  --start_points="-40,0,10;40,0,10;0,0,10" \
  --out_pkl deckga_ros2/data/deckga_output.pkl \
  --save_fig_dir results

This produces:

Waypoints dataset: data/points/points_seed11_n30_z10_100.pkl

Planner output: deckga_ros2/data/deckga_output.pkl

Figures/logs: results/

Timing outputs (printed by deckga_execute.py)

Executed timing (wall-clock): arming, takeoff, path loop, hover, landing

Mission completion time (command-level): first waypoint command → final waypoint command, and makespan
